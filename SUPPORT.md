# Support

## Getting help

- Open a Bug report for a reproducible application or notebook problem.
- Open a Feature request for a focused improvement.
- For setup questions, include your Python version, operating system, command, and exact error message.

Check the README and existing issues first. Redact credentials, personal information, and private dataset content from all reports.

For security concerns, follow SECURITY.md. Support is provided on a best-effort basis.
